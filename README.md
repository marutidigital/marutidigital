# MarutiDigital.in

A Web + SaaS powerhouse platform for Indian freelancers, companies, and tech builders. Built using the **n8n.io visual design language**.

## Tech Stack
* **Framework:** Next.js 14 (App Router)
* **Styling:** React + Tailwind CSS
* **Icons:** Lucide React
* **Theme:** HSL-based dark theme, signature orange-red accents (`#FF6D5A`)

## Features
1. **Interactive Tools Hub:** CSS glassmorphism and shadow generators, GST invoice builders, freelance rate calculators, bio-link builder, page speed indicators, WHOIS resolvers, and AI copywriting assistants.
2. **Digital Product Shop:** Dynamic category filter switches, sorting, and full shopping cart drawer integration.
3. **SaaS Products:** Subscription pricing structures with monthly vs annual billing toggles.
4. **Agency Services:** Project estimate calculators reflecting scope complexity and speed schedules.
5. **Knowledge Hub Blog:** Docs-style categorized developer blog.
6. **Community:** Discussion boards, thread creations, Discord lounges, and mastermind memberships.

## Running Locally
Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
